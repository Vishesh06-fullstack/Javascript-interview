JavaScript Revision 🚀

A structured collection of JavaScript concepts, code snippets, and practice problems built while preparing for technical interviews. This repo covers everything from DOM fundamentals to closures, async/await, and ES6+ features — with working examples, not just theory.

📌 Why this repo

Most "JS notes" repos are just bullet points. This one is different — every concept here is backed by runnable code, so you can see the behavior, not just read about it. It's a living reference I use to revise fast before interviews.

🧠 Topics covered


Core JS: Hoisting, closures, scope, this keyword
Functions: Declarations vs expressions, arrow functions, higher-order functions
Async JS: Callbacks, Promises, async/await, event loop
ES6+: let/const, template literals, destructuring, spread/rest, array methods (map, filter, reduce)
DOM: Selecting, manipulating, and interacting with the DOM
Practice: Real interview-style problems with solutions


▶️ How to use

Clone the repo and run any file with Node:

bashgit clone https://github.com/<your-username>/javascript-revision.git
cd javascript-revision
node important/closure.js

For DOM-related files, open the .html files directly in a browser.
